# SpiceOwl brand assets

The initial mark is an original, hand-authored SVG: a watchful owl with a smooth two-cycle sine waveform on its chest. It represents the project's overnight simulation-monitoring use case.

| File | Use |
| --- | --- |
| [spiceowl.svg](spiceowl.svg) | Editable source; README and scalable icon |
| [spiceowl.png](spiceowl.png) | 512 × 512 raster export for avatars and tools that require PNG |

## Palette

- Midnight: `#122238`
- Mint: `#66D9B5`
- Warm white: `#FFF6DF`
- Amber: `#E6A348`

Keep the icon square with its rounded midnight tile. Use **SpiceOwl** for the display name and `spiceowl` for the repository/package spelling. The suggested tagline is **You sleep. SpiceOwl keeps watch.**

The SVG is the source of truth; regenerate the PNG after editing it. Do not stretch the mark, replace its waveform with status text, or use color alone to indicate a runtime outcome. A future UI should present explicit status labels beside the mark.

These original assets are included under the repository's [MIT license](../../LICENSE). The icon was drawn directly in SVG; it is not a generated bitmap or a borrowed third-party logo.
