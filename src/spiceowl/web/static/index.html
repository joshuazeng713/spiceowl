添加仿真服务器

只需填写电脑上已配置好的 ~/.ssh/config 别名。登录密钥、端口和跳板机由本机 OpenSSH 自动管理，SpiceOwl 绝不保存密码。

仅允许字母、数字、短横线或下划线。
即你在终端执行 ssh my-cad-alias 时使用的别名（仅填别名，不要填整条命令）。
与远端运行 hostname 返回的准确名称一致。
与远端运行 id -un 返回的准确用户名一致。
进阶：复用该别名跳板连接到另一台节点（可选）

复用该别名的用户名、密钥与跳板路由访问另一台计算节点；目标节点仍会单独核验 SSH 指纹与身份。

进阶：指定远端仿真器绝对路径（可选，不填也能测连通）

填写远端服务器上的绝对路径；留空时仅验证 SSH 身份连通性。

点击保存只会在本地写入档案，不会立即联网，也不会改动你的 SSH 配置。保存后点击「Check connection」才会执行一次显式连通校验。
批量导入节点池 · SERVER POOL

从模板批量导入服务器

如果你有多台同配置的仿真计算节点，选一台已登记主机作为路由模板，贴入其余主机名即可一次性登记，无需重复填写。

最多 32 个不重复主机名，可用换行、空格或逗号分隔。每台机器的主机名须与远端 hostname 一致。

模板只复用 SSH 路由、用户名与工具路径，不复制主机公钥信任。导入时不会主动联网。
