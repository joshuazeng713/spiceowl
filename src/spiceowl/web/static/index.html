SERVER SETUP

Import a server pool

Select an existing host as a route template, then list the target hostnames. Only the names you provide will be registered.

Up to 32 distinct hostnames, separated by lines, spaces or commas. Each hostname must also match the remote hostname result; use Add host if these differ.

The template supplies SSH routing, expected user and tool paths. Its host-key trust is not copied. Registration does not contact these hosts.
